================================================================================
7.  When to cite v1.0 vs.\ v2.0
================================================================================

Cite v2.0  (this record):
  - if you use any version of the manuscript;
  - if you use the rendered taxonomy figure (Figure 1);
  - if you use the in-manuscript proofs (M1, N1, D2, S1, AT1, AT3, AT5, AT7).

Cite v1.0  (10.5281/zenodo.20355904):
  - only if you specifically need the snapshot before the Round-1 and
    Round-2 referee revisions.

In all other cases, prefer v2.0.
