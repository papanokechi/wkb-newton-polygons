1.  Summary of v2.0
================================================================================

v2.0 is the *camera-ready public release* of the project. It promotes
v1.0 (a dataset + proof-skeleton snapshot) to a complete, polished,
refereed manuscript with a fully-rendered taxonomy figure and full
in-manuscript proofs.

Headline numbers:

* Manuscript: 26 pages, 897,105 bytes PDF.
* Dataset: 19 JSON artifacts (~2.6 MB total) covering 96 operators.
* Atlas: 23 single-edge classes refining to 39 classes under the
  µ_q / µ_q' symmetry layer.
* Eight in-manuscript theorems with full proofs: M1, N1, D2, S1, AT1,
  AT3, AT5, AT7.
* All cross-references resolve; 0 LaTeX errors and 0 undefined
  references on a three-pass compile.

================================================================================
3.  Summary of what is NOT included
================================================================================

* Stokes constants: only directions and Galois groupoids are computed
  in this release. Numerical Stokes constants are planned for v3.0.
* Wild character varieties: only stated as a target, not proved.
* Operators with more than one irregular singularity: out of scope for
  this release.
* Numerical comparison against existing WKB packages (Mathematica
  WKBQUAD, sympy WKB, etc.) — limited spot-checks have been done but
  are not part of the release.

================================================================================
4.  Known limitations
================================================================================

* The 39-class refinement is sharp under generic hypotheses; on
  measure-zero strata (e.g. equal-modulus locus, zero-root locus),
  finer subdivisions may exist that are not exhibited in this
  release.
* Theorem 7.1 (AT1) and its three companions (AT3, AT5, AT7) are
  stated for ODE operators; the difference and q-difference
  analogues are conjectural (see §7 remarks).
* The p-visibility result (AT7) is established under (OS3) — see §7.1
  for the precise genericity hypothesis.
* Compile environment: tested on MiKTeX 25.12 / pdfTeX 4.23 and arXiv
  TeX Live 2024. Older TeX Live versions (≤ 2020) may not support all
  TikZ libraries used in the taxonomy figure.

6.  Migration from v1.0
================================================================================

Users of v1.0 can switch to v2.0 with no API changes:

* All JSON files in data/ retain their schemas (the few keys added in
  Phase IV are additive).
* fleets/fleet*.py are bit-identical to v1.0 (only documentation in
  fleets/README.md is new).
* The proofs in reports/proofs.md are unchanged in content; the
  manuscript versions are now the canonical typeset form.

Users of v1.0 who cited 10.5281/zenodo.20355904 should consider
re-citing 10.5281/zenodo.20387847 (v2.0) which contains the published
paper.
