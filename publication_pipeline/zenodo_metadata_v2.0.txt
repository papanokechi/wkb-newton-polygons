# Description (revised abstract; 186 non-math words / ≤220 target)
description: |
  This release accompanies the camera-ready manuscript "The WKB Geometry
  of Newton Polygons: A Functorial Classification Theory" and supersedes
  the v1.0 dataset (10.5281/zenodo.20355904) by promoting it to a
  complete, refereed publication.

  The central object is the constellation map F : L |-> C(L) =
  Roots(chi_L), sending a scalar linear operator L (ODE, difference, or
  q-difference, polynomial coefficients, one irregular singularity at
  infinity) to the root set of its WKB characteristic polynomial.

  The new contributions, calibrated against classical Levelt-Turrittin
  theory, are:

  (1) the χ(c) = χ_w(c^q) factorisation across each slope-graded
      block, identifying χ_w with the classical edge-indicial
      polynomial;
  (2) a finite stratified atlas of 23 single-edge classes refining
      to 39 classes under µ_q / µ_q' symmetry;
  (3) a Kummer dichotomy (Theorem 5.1) governing Z-resonances of
      χ_w;
  (4) a p-visibility result for the analytic ray positions on the
      t-cover.

  We do NOT claim new wild character variety theorems; the
  analytic-lifting theorems AT1, AT3, AT5, AT7 organise classical
  Stokes geometry under the constellation lens (§7).

  The release contains the camera-ready LaTeX manuscript (26 pp,
  897 KB PDF), the full Phase I-V computational atlas (19 JSON
  artifacts, ~2.6 MB), the arXiv-ready and journal-ready submission
  bundles, the eight in-manuscript theorem proofs (M1, N1, D2, S1,
  AT1, AT3, AT5, AT7), the agent-pipeline scripts (fleet1-fleet5),
  the phase reports, and the Round-1 + Round-2 refereed revision
  packages.
