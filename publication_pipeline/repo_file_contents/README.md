## Overview

This repository contains the **complete computational atlas, dataset, and
camera-ready manuscript** for a classification theory of scalar linear
operators (ODE / difference / *q*-difference) with one irregular singularity
at infinity.

The central object is the **constellation map**

$$
F\ :\ L \ \longmapsto\ \mathcal{C}(L)\ =\ \text{Roots}\bigl(\chi_L(c)\bigr),
$$

sending an operator $L$ to the root set of its WKB characteristic
polynomial. The theory shows that:

* $\chi_L$ factors as $\chi(c) = \chi_w(c^q)$ across each slope-graded
  block (the **$\chi_w$ factorisation**);
* the image of $F$ stratifies into a **finite atlas of 23 classes**,
  refining to **39 classes** under the $\mu_q$ / $\mu_{q'}$ symmetry layer;
* a **Kummer dichotomy** controls when the inner polynomial $\chi_w$
  admits $\mathbb{Z}$-resonances;
* the analytic lifting (Stokes geometry) is governed by the **$\Delta_{ij}$
  geometry on the $t$-cover**, with anti-Stokes directions determined by
  $\arg(c_i - c_j) + k\pi/p$.

## Quick start

### Reproduce the figures and dataset

```bash
python code/plot_constellations.py
```

### Re-run the full Phase I–V pipeline

```bash
python fleets/fleet.py    # Phase I+II : operator zoo + Newton polygons + χ
python fleets/fleet3.py   # Phase III  : multi-edge + systems + atlas
python fleets/fleet4.py   # Phase IV   : analytic lifting
python fleets/fleet5.py   # Phase V    : proof skeletons + integration map
```

### Compile the paper

```bash
cd paper
pdflatex manuscript.tex
bibtex manuscript
pdflatex manuscript.tex
pdflatex manuscript.tex
```

(Compiles cleanly: 26 pages, 0 errors, 0 undefined references.)
