================================================================================
Notes on the layout
================================================================================

* The split "code / fleets" separates executable artefacts (Python) from the
  declarative fleet manifests (YAML). All Python scripts are runnable from the
  /code directory with the inputs found in /data and produce outputs that match
  the JSON files already present.

* /theorems and /reports are kept distinct so that the formal-mathematical
  content (suitable for paper insertion) is cleanly separated from the
  narrative phase commentary.

* paper_draft.md lives in its own /paper-draft folder to mark its status as a
  preprint draft (not the canonical statement of the theory; that role is
  played by /theorems/proofs.md).

* /figures currently contains the single constellation-zoo figure produced
  by plot_constellations.py. Future versions are expected to add:
    – slope-filtration diagram (AT5),
    – p-visibility ray panels (AT7),
    – nested-ramification symmetry diagram (AT3).
